# Feature: Approval Card (UI)
**Owner:** Frontend | **Module:** Human Approval Workflow

## Goal
Clearly show the user what sensitive action the agent wants to take,
before it happens.

## Scope
- A distinct card in the chat thread: tool name in plain language (e.g.
  "Apply $10 credit to Ali's account"), the exact parameters, and
  Approve/Reject buttons.
- Visually distinct from normal messages (e.g. a warning-style border)
  so it's unmistakable this needs a decision.
